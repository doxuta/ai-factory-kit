# careful-corpus.txt — ordinary developer commands that the careful guard must leave SILENT.
#
# WHO READS ME: check-careful.test.sh (replays every entry and reports the false-positive rate);
# whoever changes the matcher. I POINT TO: ../SKILL.md (lesson 3: a guard's false-positive rate
# is a safety property — one dialog in eight commands trains people to dismiss, then to switch
# the guard off).
#
# Every entry here is routine work on some stack. None may be interrupted. If a matcher change
# flags one of them, the change is wrong or the entry is not ordinary — decide which, with
# evidence, before editing either. Commands that are ordinary but destructive by design
# (`sed -i`, `rm -rf src`, `git reset --hard`) do NOT belong here; they are pinned as asks in the
# test table.
#
# This is a CONSTRUCTED corpus, not real traffic. Replay your own shell history too (SKILL.md).
#
# Format: one command per line; `#` lines and blank lines are skipped; a line ending in `\`
# continues on the next; a block between `<<<CMD` and `CMD>>>` is one multi-line command;
# `PS> ` marks a PowerShell command.
